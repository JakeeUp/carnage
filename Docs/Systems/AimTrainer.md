# Aim trainer (`ACarnageAimTrainer`)

An Aim Labs-style practice range in one placeable actor. It needs no Blueprint. Everything is
built from engine basic shapes, one material and TextRender components.

Source: `Source/FPS_Movement/Core/Training/CarnageAimTrainer.{h,cpp}`
Material: `/Game/Carnage/Training/M_AimTarget` (generated by `Tools/Python/make_aim_trainer_assets.py`)

## Placement

All offsets are relative to the actor transform. Drop it on the floor and rotate the yaw.

| Thing | Where (default) |
|---|---|
| Origin | On the floor, centred under the target wall |
| Spawn area | Plane at X = 0, 1200 x 600 cm (`AreaExtent` 600 x 300), centre 450 cm up (`AreaCenterHeight`) |
| Backdrop | Dark wall behind it, front face at X = +120 (`BackdropOffset`), 1500 cm wide, ~1170 cm tall |
| Scoreboard | Text on the backdrop above the spawn area (`ScoreboardHeight` 420 cm) |
| Firing line | Glowing floor strip at X = -1500 (`FiringDistance`). The player stands here and looks along +X |
| Mode console | Pedestal at (-1350, -380, 0) (`ConsoleOffset`), turned to face the firing point |

The targets face -X, so the player belongs on the actor's **-X side**, about **1500 cm** away.
With the default yaw of 0 the player looks down world +X. The whole footprint is about
1500 cm (Y) x 1650 cm (X). `GetFiringPoint()` returns the world location of the stand spot.

## Modes

Shoot a console button to start that mode: GRIDSHOT, MICROSHOT or TRACKING. Shoot START to
replay the current mode. Every run opens with a 3-2-1 countdown in the middle of the board
(`CountdownSeconds`). It then runs for `RunLength` seconds (default 30).

- **Gridshot**: `GridAliveCount` (3) targets alive on a `GridColumns` x `GridRows` (5 x 3) grid,
  spaced `GridCellSize` apart. A kill spawns a replacement right away on a free cell. That cell
  is never the one just vacated. 100 points per kill.
- **Microshot**: one small target (`MicroshotTargetRadius` 12 cm) at a time, at random points in
  the area. Each new target lands at least `MicroshotMinSeparation` from the last one.
  100 points per kill.
- **Tracking-lite**: one target strafes left and right. It accelerates at `TrackingAcceleration`
  toward a random velocity up to `TrackingSpeed`, changes direction every
  `TrackingDirectionChangeInterval` seconds and turns early enough to stay inside the area. It
  also bobs vertically. Each hit scores 10 points and flashes the target. It never dies.

Kills pop: the sphere scales up to `PopScale` over `PopDuration` (0.08 s) and then vanishes.
`UCarnageWeaponFXSubsystem::PlayImpact` plays a burst using the pawn preset, which leaves no decal.

## Hits and stats

Weapon hits come in through `IShooterShootable::HandleShot`, which `ShooterDamage::ApplyHit`
calls. `Hit.HitComponent` identifies the target sphere or button that was hit.

- **Target (Gridshot / Microshot)**: returns true with `bKilled = true` and `DamageDealt = 1`, so
  the player's hitmarker and kill sound fire.
- **Target (Tracking)**: returns true with `DamageDealt = 1` and `bKilled = false`.
- **Button**: returns true with `DamageDealt = 1`, then starts the mode.
- **Backdrop, pedestal or inactive target**: returns false, so normal impact handling runs.

Shots are counted from `AShooterCharacter::OnBulletCountUpdated` on the player pawn found at run
start. A drop in the bullet count within the same magazine size counts as shots. Reloads and
weapon swaps change the count without counting as shots. Hitscan applies the hit before the ammo
drops, so the trainer matches hits and shots in either order. A shot with no hit inside
`MissGraceTime` is a miss and resets the streak.

The board shows the mode, time left, score, hits, shots, accuracy, average time-to-kill, the
current streak and the best streak, plus the session best score per mode. Average time-to-kill is
the mean time between kills, with the first measured from GO. After a run the centre of the board
shows a results summary.

All sizes, colours, timings, radii, grid settings and tracking speeds are `EditAnywhere` under
**Aim Trainer** in the details panel.

## Collision

The targets and buttons use `BlockAllDynamic`, and the backdrop and pedestal use `BlockAll`. Both
profiles block every trace channel whose default response is Block, which includes the hitscan
"Weapon" channel. Idle and popping targets have collision disabled.
